Renault Clio II 1.4 16V Diagnostic

Engine: K4J petrol

Fault code: P0335

Crankshaft Position Sensor Circuit

Possible causes

  • Faulty crankshaft position sensor
  • Damaged sensor wiring
  • Corroded connector
  • Damaged trigger wheel
  • ECU signal fault

Recommended tests

  1. Inspect sensor connector and wiring.
  2. Check sensor resistance against the correct specification.
  3. Check sensor AC output while cranking.
  4. Inspect crankshaft trigger wheel.
  5. Check whether the ECU receives an RPM signal while cranking.

Important: Confirm wiring pinouts and specifications using the exact ECU variant before testing. Do not replace parts based on the fault code alone.
